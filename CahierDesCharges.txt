#CahierDesCharges


- Choisir quelle type de TowerDefense 
- Choisir les spécificités des monstres, des tours

- Modeliser les maps ( les chemins )
- Placer l'entrée des monstres 
- Placer la sortie des monstres ( notre base )


- Choisir le prix des tours 
- Choisir le nombres de vie de notre base 
- Créer plusieurs personnages 
- Choisir une musique de fond si on veut 
- Choisir le son des monstres et des tours si on veut


Un mode de jeu « texte » (pouvant se jouer entièrement dans le terminal). Il n’a
pas vocation a être très ergonomique, nous vous le demandons pour être certains
que votre travail ne soit pas bloqué par le traitement de problèmes liés à l’interface
graphique.( OBLIGATOIRE )


L’implémentation des règles générales ( OBLIGATOIRE ) dans README.md

Un ecran d'accueil ( OBLIGATIORE ):
— Choisir le niveau de difficulté (facile, moyen ou difficile) ;
— Choisir le tableau de jeu (chemins ou décors différents) ;
— Choisir le mode de jeu (normal ou marathon).

Un écran ou on choisit notre personnage

Un écran pause :
- Choisir si on veut reprendre la partie en cours
- Choisir si on veut quitter la partie en cours ( donc revenir à la page d'accueil )
- Choisir si on veut recommencer un nouvelle partie
- Choisir si on mets le son ou la musique si on veut 

Un écran game over :
- Choisir si on veut recommencer 
- Choisir si on veut revenir à l'écran d'accueil
